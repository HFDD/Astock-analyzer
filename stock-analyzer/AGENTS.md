# AGENTS.md

## Agent skills

### Issue tracker

Issues 和 PRD 都保存在本仓库的本地 Markdown 目录 `.scratch/` 下。见 `docs/agents/issue-tracker.md`。

### Triage labels

使用五个标准 triage 标签，名称与仓库中的实际标签保持一致。见 `docs/agents/triage-labels.md`。

### Domain docs

本仓库采用单一上下文布局：根目录 `CONTEXT.md` 是全局上下文，`docs/adr/` 存放持久性的架构决策。见 `docs/agents/domain.md`。
