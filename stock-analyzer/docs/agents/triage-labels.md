# Triage Labels

本仓库使用五个标准 triage 角色；技能里提到的角色名与实际标签名保持一致。

| 技能里的角色 | 实际标签名 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者先判断和分流 |
| `needs-info` | `needs-info` | 等待提问者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求明确，可直接交给离线 agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

如果以后仓库里的真实标签改名，只改右侧这一列。
