# A股股票分析网页 - 开发计划

## 项目概述
输入A股股票代码，实时分析股票状态，给出买卖建议的单页Web应用。

## 技术架构
- 后端：Node.js + Express，负责数据获取和指标计算
- 前端：单页HTML + CSS + 原生JS
- 数据源：新浪财经API（实时行情 + 历史K线）

## 功能清单
| # | 功能 | 状态 |
|---|------|------|
| 1 | 股票代码输入 + 实时行情显示 | ⏳ |
| 2 | K线图（日K） | ⏳ |
| 3 | MA均线（5/10/20/60日） | ⏳ |
| 4 | MACD指标 | ⏳ |
| 5 | RSI指标 | ⏳ |
| 6 | KDJ指标 | ⏳ |
| 7 | 成交量分析 | ⏳ |
| 8 | 综合评分 + 买卖建议 | ⏳ |
| 9 | 热门股票快捷入口 | ⏳ |
| 10 | 响应式UI设计 | ⏳ |

## 开发顺序
1. 后端API + 数据获取
2. 技术指标计算引擎
3. 前端UI框架
4. 图表绘制（Canvas）
5. 综合评分算法
6. 联调测试
