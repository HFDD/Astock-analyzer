# A股股票分析系统 — 开发计划

## 项目概述
一个面向市场的A股股票分析Web平台，用户注册后输入股票代码，系统自动分析技术面和基本面，给出买卖建议。

## 技术栈
- 后端：Python 3 + FastAPI + SQLite + JWT
- 数据：AKShare（免费A股数据）
- 前端：HTML + TailwindCSS + ECharts
- 认证：JWT (python-jose + passlib[bcrypt])
